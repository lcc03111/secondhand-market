# 拾物 二手物品交易流转平台

基于 Flask 的模块化单体项目，支持游客浏览和搜索物品，注册用户使用同一个账号完成买卖，以及管理员审核和处理平台事务。

## 当前功能

- 注册、登录、退出；密码哈希保存；表单启用 CSRF 保护。
- 首页、物品分类、关键词和价格筛选、物品详情、收藏与举报。
- 发布物品、图片上传、我的物品、编辑、上架和下架；新发布和编辑后的物品需管理员审核。
- 站内会话、文字和图片消息、未读状态通知。
- 创建订单、卖家接受或拒绝、买家取消、人工物流录入、面交交接、确认收货和状态历史。
- 退款与纠纷申请、凭证图片、双方协商和管理员处理结果。
- 用户资料、身份核验状态流程、交易评价、系统通知。
- 管理员的物品审核、用户状态管理、分类维护、核验状态、举报、公告及基础统计。

项目范围不接入真实支付或快递接口。物流公司和运单号由卖家手动填写。身份核验只维护申请状态，不收集或保存身份证件材料。

## 在 VS Code 中运行

1. 用 VS Code 打开项目根目录，并确保安装 Python 扩展。
2. 创建 Python 虚拟环境并选择该环境作为解释器。
3. 在 VS Code 集成终端安装依赖：`pip install -r requirements.txt`。
4. 将 `.env.example` 复制为 `.env`，把 `SECRET_KEY` 替换为随机字符串。
5. 默认使用 SQLite，首次启动会自动创建数据库和默认分类。需要 MySQL 时，在 `.env` 设置 `DATABASE_URL`，并先创建对应数据库。
6. 按 F5 启动 Flask 调试配置，或运行 `python run.py`，然后访问 `http://127.0.0.1:5000`。

## 初始化管理员

在 VS Code 集成终端执行 `flask --app run.py create-admin`，按提示输入管理员用户名、昵称和密码。不要使用公开或固定的管理员密码。

## 默认页面

- `/`：首页
- `/items`：物品搜索和筛选
- `/auth/register`、`/auth/login`：注册和登录
- `/my/items`：本人发布的物品
- `/orders`：买入和卖出订单
- `/messages`：站内消息
- `/profile`：个人资料和身份核验状态
- `/admin`：管理员后台

数据库文件位于 `instance/app.db`；上传图片和纠纷凭证保存在 `instance/uploads/`。部署到生产环境前，应使用强随机密钥、HTTPS、生产级数据库和外部文件存储，并关闭调试模式。
